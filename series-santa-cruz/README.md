# Series de tiempo

Extract of the supplied archive's public-data workflow. Use the downloader to retrieve series directly from the Argentine open-data API.

Example:
`python series-santa-cruz/traer_serie.py 45.2_ECTDTRG_0_T_46 2010`

Selected IDs documented in the archive:
- 45.2_ECTDTRG_0_T_46 — Río Gallegos unemployment, quarterly.
- 45.1_ECTDTP_0_A_43 — Patagonia unemployment, annual.
- 350.1_SANTA_CRUZRUZ__27 — provincial exports.
- 367.3_SPSE_SANTARUZ__15 — electricity demand.

Compare equivalent reference periods and units. EPH agglomerate figures do not represent the entire province. The original 210-series catalogue is not included in this extract.
